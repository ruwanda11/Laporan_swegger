# API POSTINGAN (SWAGGER)

Project ini merupakan API sederhana menggunakan Node.js, Express.js, dan PostgreSQL.

API ini digunakan untuk mengelola data postingan yang berisi judul, isi, dan gambar.

## Fitur

- Menampilkan postingan
- Menambah postingan
- Upload gambar
- Dokumentasi API menggunakan Swagger

## Teknologi

- Node.js
- Express.js
- PostgreSQL
- Swagger
- Multer

## Cara Menjalankan Project

1. Download project

2. Install node modules

npm install

3. Buat file .env berdasarkan .env.example

4. Jalankan server

node index.js

## Akses Swagger

http://localhost:3000/api-docs
